## Problem
Write a procedure `is_l ittl e_end ian` that will return 1 when compiled and run on a little-endian machine, and will return 0 when compiled and run on a big-endian machine. This program should run on any machine, regardless of its word size.

## Explanation
Store the integer value 1 and inspect its lowest-addressed byte by casting its address to `unsigned char*`. On a little-endian machine the least significant byte is stored first so it will be 1, otherwise 0.
